Добрый день!

Судя по файлам `pyproject.toml` и `uv.lock`, вы используете современный и очень быстрый менеджер пакетов **uv**. Ваша структура выглядит отлично и соответствует лучшим практикам.

Под «созданием директорий и вызовом вложенных файлов» можно понимать две разные вещи: **работу с кодом** (импорт модулей) и **работу с данными** (чтение текстовых/дата-файлов). Разберем оба варианта.

---

### 1. Как создавать новые директории

**Вариант А: Вручную (через IDE или терминал)**
Проще всего создать папку через интерфейс вашей IDE (VS Code, PyCharm) или в терминале, находясь в корне проекта `TypePython/`:

```bash
mkdir utils
mkdir data
```

**Вариант Б: Программно (через Python)**
Если вам нужно, чтобы папка создавалась автоматически при запуске скрипта (например, для сохранения логов или данных), используйте современную библиотеку `pathlib`:

```python
from pathlib import Path

# Создаем папку 'logs', если её нет
Path("logs").mkdir(parents=True, exist_ok=True)
```

---

### 2. Как «вызывать» вложенные файлы Python (Импорт кода)

Если вы создали новую папку (например, `utils/`) и положили туда python-файл (например, `helpers.py`), ваша структура станет такой:

```text
TypePython/
├── main.py
├── utils/
│   ├── __init__.py   # Пустой файл, делающий папку "пакетом" (опционально в Python 3.3+, но рекомендуется)
│   └── helpers.py    # Ваш код
```

**Как импортировать в `main.py`:**
Запускать код нужно всегда **из корня проекта** (`TypePython/`). В `main.py` вы используете **абсолютный импорт**:

```python
# main.py
from utils.helpers import some_function  # Импортируем конкретную функцию
# или
import utils.helpers                     # Импортируем весь модуль
```

**Как запустить вложенный файл напрямую:**
Если вы хотите запустить `helpers.py` как самостоятельный скрипт из терминала, **обязательно** используйте флаг `-m` и запускайте из корня проекта, чтобы Python правильно понял пути:

```bash
python -m utils.helpers
```

### 3. Как «вызывать» вложенные файлы с данными (Чтение txt, csv, json)

Если вы создали папку для данных (например, `data/`) и положили туда файл `users.txt`, структура выглядит так:

```text
TypePython/
├── main.py
└── data/
    └── users.txt
```

Чтобы прочитать этот файл из `main.py`, **никогда не используйте просто имя файла** (`open("data/users.txt")`), так как это сломается, если вы запустите скрипт из другой папки.

Всегда используйте `pathlib` и привязку к текущему файлу (`__file__`):

```python
# main.py
from pathlib import Path

# Получаем абсолютный путь к папке, где лежит main.py
BASE_DIR = Path(__file__).resolve().parent

# Формируем путь к файлу data/users.txt
file_path = BASE_DIR / "data" / "users.txt"

# Читаем файл
with open(file_path, "r", encoding="utf-8") as f:
    content = f.read()
    print(content)
```

_Этот подход гарантирует, что файл найдется, откуда бы вы ни запустили `main.py`._

### Резюме (Best Practices для вашего проекта):

1. **Код (модули):** Создавайте папки для группировки логики (например, `services/`, `api/`, `utils/`). Импортируйте их в `main.py` через точку: `from utils.helpers import ...`.
2. **Данные (файлы):** Создавайте папки для хранения входных/выходных данных (например, `data/`, `logs/`, `exports/`). Обращайтесь к ним через `Path(__file__).parent / "data" / "file.txt"`.
3. **Тесты:** У вас уже есть папка `tests/`. Файлы оттуда импортируются аналогично: `from tests.test_main import ...` (если нужно), но чаще всего тесты запускаются автоматически через `uv run pytest`.
4. **Запуск:** Всегда выполняйте команды (`uv run python main.py`, `uv run pytest`) находясь в корневой папке `TypePython/`.
